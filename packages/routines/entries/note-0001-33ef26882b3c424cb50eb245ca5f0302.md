## Level 3 — Routines: Stop Reinventing Successful Work

**The constraint this solves:** repeating successful work is tedious. An AI-assisted process might successfully produce a design structure matrix, an analysis, a review package — but reproducing that same outcome later often means reconstructing the entire sequence of prompts and actions from memory.

**Cartenza's response:** elevate the knowledge record into something executable. Instead of only documenting *what* worked, capture a sequence an agent can actually run again. This is the first real shift from storing knowledge to executing it.

**What this looks like in practice:** `routine_def` entries in `knowledge_repo` (`list_routines`, `validate_routine_def`, `render_routine_prompt` to dry-run the template before a real execution). Running one uses `workspace_manager` for the actual working outputs, per-execution — see `getting_started`'s server-disambiguation table.

**A concrete signal you're working at this level:** you've caught yourself doing the same multi-step task by hand more than once, and the thought "this should just be a routine" has actually occurred to you — not hypothetically, about a real, specific, repeated task.
